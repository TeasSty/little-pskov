# Литл — детская фотостудия, Псков

Одностраничный сайт для [VK-сообщества little_pskov](https://vk.ru/little_pskov): зоны, пакеты съёмки, FAQ и запись.

## Локальный просмотр

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
npx --yes serve .
```

## GitHub Pages

Репозиторий настроен на публикацию из корня ветки `main`.
